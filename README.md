# 신흥세라믹 팔레트별 패킹리스트 웹앱

발주서 엑셀(.xlsx)을 브라우저에 올리면 팔레트별 패킹리스트를 만들어 인쇄/PDF로 저장한다.

**주소:** https://dybroskr-maker.github.io/shinheung-packing/

- 서버 없음. 엑셀 파싱·집계·출력이 전부 접속한 사람의 브라우저 안에서만 일어나며 파일은 어디에도 업로드되지 않는다.
- 엑셀 파서(SheetJS)는 CDN에서 불러온다. 같은 폴더에 `xlsx.full.min.js`를 두면 그 파일을 먼저 쓰므로 오프라인에서도 동작한다.
- Numbers 파일은 엑셀(.xlsx)로 저장한 뒤 올린다.

## 읽는 규칙

- 팔레트 열: 헤더에 `팔레트`가 든 열을 자동 탐지(열 위치 고정 아님)
- B=위치(`^\d{3}-.+-\d+$`), C=석종, F=너비, G=길이, H=수량EA, L=M2(없으면 W×L×EA/1,000,000)
- 발주동/구간: 시트에 여러 동이 섞이면 `NNN동`/시트tier, 단일 동이면 B3의 CD-N/시트명tier
- 석종 약어 AVORIO→AV, GRIGIO·GRIGRO→GR, NOCE→NO. AVORIO 행은 석종칸 분홍
- 한 팔레트 24행 초과 시 페이지 분할, 마지막 페이지에 수량·M2 합계
- 팔레트칸이 `11번파레트에 76 12파레트에 나머지` 식이면 수량을 나눠 배분하고 위치 뒤에 `(NN장)` 표기
- `가공상세도` 시트는 제외

읽어들인 뒤 팔레트 번호에 빠진 번호가 있으면 화면 위쪽에 경고로 알린다.

## 인쇄

A4 세로, 여백 12mm. 브라우저 인쇄 대화상자에서 머리글·바닥글은 끄고 배경 그래픽은 켜야 분홍 강조가 나온다.
